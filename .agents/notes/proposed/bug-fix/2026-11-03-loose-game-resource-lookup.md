# 完整散装游戏的标题合成资源查找失败

Status: proposed

## 已知事实

L1 验证中，解包 data.xp3 的全部文件后，原 startup 能够执行，
但在 custom.ks 标题界面遇到 `title@背景%base` 图片查找/加载异常，测试明确失败。
仅用自制 startup 注册 data.xp3 搜索路径再执行原 startup 的引导场景则运行到 `title.ks:33`。
后者仍把素材留在归档，不能证明完整散装资源兼容。
当时构建与完整验证范围见[Desktop CLI 验证](../../implemented/testing/2026-11-02-desktop-cli-validation.md)。

## 下一步

在全新私有副本复核失败，记录各资源来源、搜索路径、合成图片标识解析和实际打开的存储名。
对比归档内与散装文件路径的规范化、大小写和补丁优先级，再定位资源映射失败的具体层次。
原始商业样本保持不变，提取复现规律后使用自制素材构造可分发的最小用例。

## 完成条件与风险

相同资源查找规则在归档与散装最小用例中得到预期结果，真实副本的原失败位置通过。
变更不能改变多归档和 patch 的既有查找优先级。
尚无根因，不通过删除脚本、改名资源或仅保留归档素材关闭该问题。
